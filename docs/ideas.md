# Ideas de proyecto

## SAMAPP

SAMAPP es una aplicación que permite a los refugios de adopción de mascotas, publicar nuevas opciones de adopción, siendo el intermediario entre el adoptante y el refugio. Además de mostrar información relevante como edad, peso, tamaño, raza, comportamiento, etc. Lo que permite dar un mejor vistazo para las personas que se animen a adoptar una mascota con nuestra aplicación.

Aplicaciones similares:

- Petfinder (https://www.petfinder.com/)
- Adoptme (https://apps.apple.com/co/app/adoptme-find-a-pet/id1599782241)

## FoodMatch

FoodMatch es una aplicación para la recomendación de restaurantes o lugares para comer, de acuerdo a los gustos, ubicación o menús que el usuario esté buscando en particular. Donde la aplicación compara esta información con una base de datos y sugiere los establecimientos más cercanos que compran con las características.

Aplicaciones similares:

- Google Maps (https://apps.apple.com/co/app/google-maps/id585027354)
- Yelp (https://apps.apple.com/co/app/yelp-restaurants-places/id284910350)
- Tripadvisor (https://apps.apple.com/co/app/tripadvisor-planifica-viajes/id284876795)

## Parking Slot

Será una aplicación para la gestión y administración de parqueaderos, diseñada para facilitar el control de vehículos, espacios disponibles, ingresos y salidas.

Aplicaciones similares:

- EasyPark (https://play.google.com/store/apps/details?id=net.easypark.android&pli=1)
